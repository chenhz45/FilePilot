# FilePilot — 功能需求文档

## 项目概述
FilePilot 是一款跨平台（macOS + Windows）桌面文件自动整理工具，帮助用户自动分类、归档桌面文件，保持桌面整洁。

## 核心功能

### 1. 目标文件夹监视
- 可设置一个监视文件夹（默认为系统桌面）
- 支持手动扫描或实时监视两种模式

### 2. 规则整理
- **按扩展名分类**：用户可定义"扩展名 → 目标文件夹"的映射规则
  - 例如：.jpg/.png/.gif → 图片，.pdf/.doc/.docx → 文档
- **按修改时间归档**：将超过 N 天未修改的文件移动到 `归档/年-月` 子目录

### 3. 两种运行模式
- **实时模式**：监视文件夹中的文件创建/修改事件，自动触发整理
- **手动模式**：点击按钮，扫描并整理一次

### 4. 规则配置界面
- 增、删、改"扩展名 → 目标文件夹"映射规则
- 规则保存到本地 JSON 配置文件
- 支持启用/禁用单条规则

### 5. 操作日志
- 记录每次移动的源路径、目标路径、时间戳
- 支持撤销上一步移动操作

### 6. 辅助功能
- **忽略列表**：排除特定子目录（如已整理好的文件夹），避免递归移动
- **防冲突处理**：目标已存在同名文件时，自动重命名（如 file(1).jpg）
- **系统通知**：整理完成后弹出系统通知

## 非功能需求
- 跨平台：macOS 和 Windows 统一体验
- 轻量级：单 JSON 配置文件，无需数据库
- 安全：移动而非删除文件，提供撤销功能
- UI：干净、极简、高级，macOS Sonoma 风格，同时适配 Windows
